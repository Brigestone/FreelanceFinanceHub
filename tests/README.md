# FreelanceFinanceHub - Suite de Pruebas

Este directorio contendrá las pruebas automatizadas del proyecto organizadas en:

- `unit/`: Pruebas unitarias aisladas para el motor matemático de la calculadora (`calculationEngine.test.js`) y utilidades.
- `integration/`: Pruebas de integración sobre los endpoints de la API (`auth.test.js`, `subscriptions.test.js`) utilizando Supertest y Jest.

Las pruebas se implementarán formalmente a partir de las fases de lógica de negocio (Fase 3 en adelante) conforme al plan de desarrollo aprobado.
